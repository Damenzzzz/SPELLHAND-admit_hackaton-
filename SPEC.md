## 4. Распознавание жестов (ядро, собственная логика)

### 4.1 Признаки (`features.ts`)
MediaPipe Hand: 0 wrist; большой 1–4; указательный 5–8; средний 9–12; безымянный 13–16; мизинец 17–20 (MCP, PIP, DIP, TIP).

- **palmSize** = dist(0, 9) — нормализатор всех расстояний (инвариант к удалённости от камеры).
- **Палец выпрямлен/согнут**: угол в PIP (MCP–PIP–TIP). > 160° → 1.0 (выпрямлен), < 110° → 0.0 (согнут), между — линейно. Большой палец: угол в MCP (2–3–4) + dist(4, 5)/palmSize.
- **Ладонь к камере**: нормаль = cross(v(0→5), v(0→17)), знак z с учётом handedness. **Знак откалибровать эмпирически** (MediaPipe считает handedness для зеркального селфи-изображения).
- **Высота руки**: wrist.y в координатах кадра (0 — верх).
- **Движение** (`motion.ts`): кольцевой буфер ~15 кадров; скорость wrist в palmSize/сек; **толчок** = рост palmSize ≥ 15% за ≤ 250 мс; **свайп** = |vx| или |vy| выше порога.
- Все landmarks проходят через **One Euro filter** (иначе дребезг).

### 4.2 Шаблон жеста (`types.ts`)
```ts
type Constraint = {
  id: string;                        // 'index_extended', 'palm_facing', 'hand_above_head'...
  weight: number;
  score: (f: HandFeatures, ctx: FrameCtx) => number; // 0..1, мягкие пороги
  hint: string;                      // КОНКРЕТНАЯ подсказка на русском
  fingers?: FingerId[];              // какие пальцы подсветить красным при провале
};
type GestureTemplate = {
  id: SpellId | 'shield';
  hands: 1 | 2;
  pose: Constraint[];                // статическая форма
  motion?: MotionTrigger;            // что запускает каст (толчок/свайп) + подсказка при провале
};
```

### 4.3 Матчинг (`matcher.ts`)
- `score = Σ(w·s)/Σw` по каждому шаблону каждый кадр.
- **Распознано**: лучший шаблон ≥ **0.85** стабильно **5 кадров** → поза «взведена», ждём motion-триггер (если есть).
- **Near-miss (режим «ошибка»)**: лучший шаблон в **[0.55; 0.85)** дольше **400 мс** → показать **1–2 ограничения с худшим score** этого шаблона: текст подсказки + красная подсветка пальцев + призрачная рука-шаблон рядом.
- **Осечка движения**: поза верная, но motion-триггер слабый (например толчок < 15%) → «Толкни ладонь к камере резче».
- Контекстные ошибки (приоритетнее всех): руки нет в кадре / нужна вторая рука / рука слишком близко (palmSize > порога) → «Отойди на шаг назад» / слишком далеко / низкая уверенность детекции → «Мало света — повернись к окну/лампе».
- **Качество каста** `quality = score` на момент каста → множитель силы (см. 5.2).
- Все пороги — в одном конфиге, есть dev-панель (`?dev=1`) со score каждого шаблона в реальном времени для тюнинга.

### 4.4 Шесть жестов

| Действие | Поза | Триггер | Примеры подсказок (near-miss) |
|---|---|---|---|
| 🔥 **Огненный шар** | открытая ладонь, все 5 выпрямлены, ладонь к камере | держать = заряд (0.5–1.5 с), **толчок к камере** = выстрел | «Выпрями безымянный палец», «Разверни ладонь к камере», «Толкни ладонь вперёд резче» |
| ❄️ **Ледяные осколки** | указательный + средний выпрямлены, безымянный + мизинец согнуты | каждый **резкий кивок кистью вниз** = осколок (до 3) | «Согни мизинец», «Сведи указательный и средний вместе» |
| ⚡ **Молния** | только указательный вверх, рука **выше уровня головы** (wrist.y < 0.3) | **быстрый свайп вниз** | «Подними руку выше головы», «Остальные пальцы сожми в кулак», «Махни вниз быстрее» |
| 🌪️ **Порыв ветра** | **две** открытые ладони | **синхронный горизонтальный свайп** обеими | «Нужны обе руки в кадре», «Веди обе руки в одну сторону одновременно» |
| 💚 **Исцеление** | **две** ладони рядом (dist запястий < 1.2·palmSize), пальцы выпрямлены | держать (лечит, пока держишь, но щит недоступен) | «Сведи ладони ближе друг к другу» |
| 🛡️ **Щит** | кулак (все пальцы согнуты), ладонь к камере | держать = щит поднят | «Сожми кулак плотнее — указательный не согнут» |

## 5. Боевая система

### 5.1 Ресурсы
- HP 100, мана 100 (реген 12/с). Щит: прочность 100 (зависит от предмета), при 0 — **ломается** (VFX трещин → осколки), кулдаун 6 с, затем восстановление.
- Трещины на щите отображаются по мере падения прочности (шейдер/текстура).

### 5.2 Заклинания (дефолты, всё в `data/spells.ts`)
| Спелл | Урон | Мана | КД | Характер |
|---|---|---|---|---|
| Огненный шар | 18–35 (от заряда) | 25 | — | burst, заряжаемый |
| Ледяные осколки | 3×6 | 20 | 1.5 с | мульти-хит, замедляет каст врага на 20% на 3 с |
| Молния | 28 | 40 | 4 с | мгновенная, пробивает 50% щита |
| Порыв ветра | 8 + 40 по щиту | 25 | 3 с | контроль: сбивает заряд врага, ломает щиты |
| Исцеление | +20 HP за 2 с | 35 | 8 с | саппорт, пока держишь — нет щита |

**Итоговый урон** = база × `(0.6 + 0.4·quality)` × множители посоха. Точный жест бьёт сильнее — режим «ошибка» встроен в механику, а не только в UI.

**Контр-логика**: щит полностью гасит огонь и лёд (урон уходит в прочность); молния пробивает 50%; ветер наносит щиту ×3.

### 5.3 Бот (`ai.ts`)
Машина состояний: `idle → выбор спелла (веса уровня) → телеграф (руна заряда над врагом, 0.5–1.2 с) → каст`. Телеграф даёт игроку окно поднять щит — делает щит осмысленным. Реакция: с вероятностью `shieldReact` бот ставит щит, когда игрок заряжает огненный шар.

### 5.4 10 уровней (`data/levels.ts`, только данные)
| Ур. | Параметры |
|---|---|
| 1–2 | HP 60–80, только огонь, каст раз в 3 с, телеграф 1.2 с, без щита |
| 3–4 | + лёд, щит с вероятностью 0.2 |
| **5 — босс** | HP 150, щит отражает 20% урона обратно |
| 6–9 | + молния/ветер, каст 2.0 → 1.4 с, телеграф 0.9 → 0.6 с, shieldReact до 0.6 |
| **10 — финальный босс** | HP 200, две фазы (на 50% HP ускоряется и лечится один раз) |

Поля уровня: `id, name, enemyPortrait, arena, hp, spellWeights, castInterval, telegraphMs, shieldReact, reward`. Следующий уровень открывается после победы.

## 6. Режим «ошибка» — полный набор (20 баллов, описать в SUBMISSION.md)

1. **В реальном времени**: near-miss → карточка с конкретной подсказкой + красные пальцы на скелете + призрачная рука-шаблон.
2. **В механике**: качество жеста = сила заклинания; осечка движения = заклинание не срабатывает с объяснением почему.
3. **Академия** (обучение): по каждому жесту — живой чек-лист ограничений ✓/✗ («Указательный выпрямлен ✓», «Ладонь к камере ✗»), призрачная рука, 3 успешных каста = жест изучен.
4. **Итоги боя**: точность кастов в %, средний quality по каждому спеллу, **топ-3 ошибки со счётчиком** («Большой палец не прижат — 7 раз») и совет, что тренировать.

## 10. Пайплайн ассетов (Фаза 3, делать параллельно отдельной сессией Claude Code)

### 10.1 Принципы
- Ассеты генерятся **офлайн** и коммитятся. Игра грузит только статику.
- Единый **`scripts/style-bible.md`**: один стиль для всего, например «stylized hand-painted fantasy, dark navy + arcane blue + gold accents, soft rim light, clean silhouette, game asset» + негатив-промпт. Первое сгенерированное изображение-эталон передаётся **референсом** во все следующие генерации Nano Banana 2 (поддерживает несколько референсов) → консистентность.
- **`scripts/assets.manifest.json`** — единственный источник: `{ id, type: 'image'|'model', prompt, refs[], size, bg, out, status }`. Скрипты идут по манифесту и проставляют `status: done`.

### 10.2 2D (Nano Banana 2)
- `scripts/gen-images.ts`: `@google/genai`, модель `gemini-3.1-flash-image` (черновики — `gemini-3.1-flash-lite-image`, финал логотипа/ключевого арта — `gemini-3-pro-image`).
- Нужны прозрачные PNG (иконки, портреты)? Генерить на однотонном фоне `#00FF00` и вырезать хромакеем через `sharp`.
- Список: логотип; 10 арен (или 5 × 2 варианта освещения); 10 портретов врагов (2D + idle-анимация покачивания/свечения — без 3D-риггинга); 5 иконок спеллов; 5 иконок посохов; 3 рунических круга для щитов (текстура); фон меню.

### 10.3 3D (Meshy MCP → GLB)
- Подключение: `npx add-mcp @meshy-ai/meshy-mcp-server --env MESHY_API_KEY=...` (или REST напрямую).
- Флоу на каждый посох: Nano Banana 2 → концепт-арт посоха на белом фоне (вид сбоку, целиком) → **image-to-3D** в Meshy → скачать GLB → `optimize-models.sh`.
- **Перед генерацией проверить баланс кредитов** (`get_balance`). Сначала 1 посох end-to-end, потом остальные.
- Только **5 посохов** в 3D. Щиты — текстурированный круг (дешевле и выглядит лучше), враги — 2D.
- `optimize-models.sh`: `npx @gltf-transform/cli optimize in.glb out.glb --compress meshopt --texture-compress webp --texture-size 1024`. Цель: ≤ 2 МБ на модель.
- Fallback, если генерация не выходит за 1 час: Tripo API v3 или CC0-модели (Kenney) — указать в README.

### 10.4 Звук
Короткие SFX (каст/попадание/щит/поломка/победа/поражение) — из CC0-библиотек или генерация; указать источники в README.
