# SPELLHAND — дуэль магов на жестах

Браузерная игра для Admit Hackathon (кейс «Motion», направление Game): заклинания кастуются жестами рук перед веб-камерой. Меню, бой, академия и магазин полностью управляются руками.

**Демо:** https://spellhand-ruddy.vercel.app (Chrome, нужна веб-камера)

## Управление

| Действие | Поза | Движение-триггер |
|---|---|---|
| 🔥 Огненный шар | открытая ладонь к камере, все пальцы выпрямлены | держать = заряд (0.5–1.5 с), **толчок к камере** = выстрел |
| ❄️ Ледяные осколки | указательный + средний выпрямлены и сведены, остальные согнуты | каждый **резкий кивок кистью вниз** = осколок (до 3) |
| ⚡ Молния | только указательный вверх, рука выше головы | **быстрый взмах вниз** |
| 🌪️ Порыв ветра | две раскрытые ладони врозь | **обе руки в одну сторону** одновременно |
| 💚 Исцеление | две раскрытые ладони рядом | держать (лечит, щит недоступен) |
| 🛡️ Щит | кулак пальцами к камере | держать |

**Меню:** наведи указательный палец на кнопку и подержи 1.2 с (dwell-клик).

**Продвинутое:**

| Приём | Как |
|---|---|
| ✍️ Руны-ультимейты | сведи большой и указательный (👌 «перо») и нарисуй в воздухе: △ Метеор, Z Цепная молния, V Ледяная тюрьма, ○ Сфера, спираль Возрождение |
| 🛡️ Парирование | сожми кулак в последние 200 мс до попадания — снаряд отражается во врага |
| 🔥 Перезаряд | полный заряд за 1.5 с; держишь дольше 2.3 с — шар взрывается в руке |
| ⚡ Комбо | лёд → молния за 1.5 с = «Шторм», огонь → ветер = «Огненный вихрь» |
| 🧍 Тело (опционально) | наклон корпуса — уклонение, скрещённые руки — супер-щит, руки вверх — медитация (+мана) |

## Как работает распознавание (своя логика, без обученной модели)

1. **MediaPipe HandLandmarker** (self-host в `public/mediapipe/`) даёт 21 точку каждой руки.
2. **One Euro filter** (`src/vision/oneEuro.ts`) убирает дребезг точек без заметной задержки.
3. **Признаки** (`src/vision/features.ts`): выпрямленность каждого пальца по углам в суставах, ориентация ладони по нормали `cross(0→5, 0→17)` с учётом руки, размер ладони как нормализатор, высота руки.
4. **Шаблоны** (`src/gestures/templates.ts`) — это данные: у каждого жеста список ограничений с весом, мягким score 0..1, строкой чек-листа и конкретной подсказкой.
5. **Матчер** (`src/gestures/matcher.ts`): `score = Σ(w·s)/Σw`; поза «взведена» при ≥ 0.85 пять кадров подряд; затем ждём движение (`src/gestures/motion.ts`: толчок = рост размера ладони ≥ 15% за 250 мс, свайпы по скорости в ладонях/сек).
6. Калибровка определяет знак нормали ладони по открытой ладони игрока — камера может размечать руки зеркально.
7. **Идентичность рук** (`src/gestures/handIdentity.ts`) — по ближайшему запястью между кадрами, метка Left/Right усредняется голосованием: перепутанная на кадр метка не сбрасывает фильтр и позу.
8. **Намерение** (`intent` в шаблонах): подсказки near-miss даются только по жесту, который игрок явно пытается показать.
9. **Персональная калибровка** (`src/gestures/personal.ts`, Академия → «Под мою руку»): 22-мерный вектор формы руки, свой kNN с радиусом отказа leave-one-out; уверенно похожая на личный образец рука поднимает свой жест и подавляет соседние.
10. **Руны** (`src/gestures/runes/`): свой point-cloud распознаватель по статье $P (Vatavu, Anthony, Wobbrock 2012) + трекер пера с гистерезисом; раздельная нормировка осей и «недорисованные» эталоны для неидеальных фигур в воздухе.
11. **Поза** (`src/vision/pose.ts`): MediaPipe Pose lite через кадр; калибровка нейтральной стойки, уклонение — наклон > 0.35 ширины плеч.
12. Детекция идёт в **Web Worker** (ImageBitmap transfer, один кадр в полёте) с откатом на главный поток.

Все пороги — в `src/gestures/config.ts`, в `?dev=1` видно score каждого шаблона в реальном времени.

## Режим «ошибка»

- **В реальном времени:** если лучший шаблон в диапазоне 0.55–0.85 дольше 400 мс, показываются 1–2 проваленных ограничения («Выпрями безымянный палец»), эти пальцы красные на скелете, рядом призрачная рука-шаблон.
- **Осечка движения:** поза верная, но движение слабое → «Толкни ладонь вперёд резче», каст не срабатывает.
- **Контекст:** нет руки, слишком близко/далеко, мало света.
- **В механике:** итоговый урон = база × (0.6 + 0.4·качество жеста); монеты за победу получают бонус до +50% за точность.
- **Академия:** живой чек-лист ✓/✗ по каждому ограничению, призрачная рука, 3 успешных каста = жест изучен.
- **Итоги боя:** точность, среднее качество по спеллам, топ-3 ошибки со счётчиком и совет, что тренировать; карточка результата PNG с QR.
- **Оценки каста:** ИДЕАЛЬНО (×1.2) / ХОРОШО / СЛАБО — при слабом касте игра называет самое слабое ограничение; серия удачных кастов даёт до +25% урона.
- **Таксономия причин:** ✋ форма руки, ↯ движение, 📷 кадр, 💡 свет — отдельно от ⏳ перезарядки и 💧 маны.
- **Руны и парирование** тоже объясняют провал: «рисуй крупнее», «похоже на Метеор — замкни фигуру», «рано на 250 мс».
- **Тренер:** точность по сессиям («было 47% → стало 75%»), тепловая карта пальцев, частые ошибки и 30-секундное упражнение на самую частую.
- **Разминка** (стрик ×10) и **испытание дня** (одинаковый для всех бой с модификатором и своим рейтингом).

## Игра

- 10 уровней кампании (`src/game/data/levels.ts`), боссы на 5 (отражение урона щитом) и 10 (вторая фаза).
- Бот: idle → выбор спелла → телеграф (руна над врагом) → каст; ставит щит в ответ на заряд игрока.
- Контр-логика: щит гасит огонь и лёд, молния пробивает 50%, ветер ломает щиты и сбивает заряд.
- Магазин: 5 посохов и 3 щита (`src/game/data/items.ts`), прогресс в localStorage.
- Звуки синтезируются Web Audio (`src/game/sfx.ts`); музыка — CC0 (см. «Ассеты»).
- Стихии: огонь поджигает (снимается льдом/лечением), ветер сдувает вражеские снаряды, бот с 6-го уровня уклоняется.
- **AR-посох:** экипированный 3D-посох (GLB) держится в руке на видео — позиция по запястью, направление запястье → MCP среднего пальца, навершие светится цветом взведённого заклинания (`src/render/StaffAttachment.tsx`, React Three Fiber). Пальцы перекрывают древко (depth-only капсулы по костям).
- **AR-эффекты на руке** (`src/render/ar/`): GPU-частицы — огонь в ладони растёт с зарядом, иней на пальцах, молния из кончика указательного, искры лечения и ветра, след пера руны.

## Онлайн

Своего бэкенда нет — всё P2P, поэтому игра работает с одной ссылкой без регистрации и ключей.

- **Матчмейкинг и бой** (`src/net/matchmaking.ts`, `src/net/pvp.ts`): WebRTC через [Trystero](https://github.com/dmotz/trystero), сигналинг — публичные Nostr-релеи. Presence в комнате `lobby`: два самых ранних свободных игрока — пара, игрок с меньшим id предлагает матч, оба уходят в комнату `match-{roomId}`.
- События: `ready`, `countdown {startAt}`, `cast {spell, damage, quality, …}`, `state {hp, shield…}` каждые 250 мс, `end`. Каждый клиент авторитетен по **своему** HP: входящий каст разрешается его щитом. Статы посохов и щитов работают и в PvP.
- **Нет соперника за 20 с → бой с ботом «Призрак мага»** — одиночный игрок не застревает.
- **Финты и живая рука:** сопернику виден жест, который ты взводишь, и скелет твоей руки (21 точка ~12 раз/с вместо видео — картинка с камеры не уходит с устройства).
- **Лидерборд** (`src/net/leaderboard.ts`): каждый результат — подписанное событие NIP-78 на публичных Nostr-релеях с анонимным ключом устройства; топ-20 по победам и точности. Античита нет (хакатон).
- Supabase не подключали: для этого нужен аккаунт. Транспорт изолирован в `src/net`, у Trystero есть стратегия `@trystero-p2p/supabase` с тем же API.

## Ассеты

Все ассеты сгенерированы офлайн и закоммичены в `public/assets` — ключи генерации в клиент не попадают.

- **2D (Nano Banana 2, `gemini-3.1-flash-image`):** `scripts/gen-images.ts` идёт по `scripts/assets.manifest.json` (36 позиций: логотип, фон меню, 10 арен, 10 портретов врагов, 6 иконок заклинаний, 5 концептов посохов, 3 руны щитов). Единый стиль — `scripts/style-bible.md`; первое изображение передаётся референсом во все остальные. Прозрачность — хромакей #00FF00 через `sharp`, результат в WebP.
  ```bash
  node --env-file=.env scripts/gen-images.ts --concurrency 1   # GEMINI_API_KEY (Gemini API или Vertex AI Express)
  ```
- **3D-посохи:** Meshy/Tripo/Blender были недоступны, поэтому 5 посохов смоделированы процедурно в коде (`scripts/build-staffs.mjs`: three.js → GLB), по концепт-артам из Nano Banana, затем `scripts/optimize-models.sh` (gltf-transform + meshopt, 12–24 КБ на модель). Превью: `npm run dev` → `/scripts/preview-staffs.html`.
- **Навершия посохов из image-to-3D:** `scripts/gen-staff-heads.mjs` (TRELLIS.2, MIT, HF Spaces) — пайплайн проверен, для генерации нужен `HF_TOKEN`.
- **Музыка (CC0, OpenGameArt):** «Town Theme» — cynicmusic (меню), «Battle Theme» — wolfgang (бой). Потоковая загрузка, не мешает старту.
- Модели MediaPipe (`hand_landmarker.task`, `pose_landmarker_lite.task`) закоммичены — установка не зависит от googleapis.
- Всё грузится заранее с прогресс-баром на экране калибровки.

## Локальный запуск

```bash
npm i          # postinstall копирует wasm MediaPipe в public/mediapipe (модели уже в репо)
npm run dev
npm test       # 75 тестов: распознаватель, руны, поза, калибровка, бой, прогресс
```

`?dev=1` — скрытый dev-режим: панель score шаблонов, мышь в меню, клавиши F/I/L/W (каст), H/S (держать лечение/щит), D (уклонение), M (медитация), `__spellhand.hands([...])` / `__spellhand.raw([...])` в консоли — синтетические руки вместо камеры, кнопка **«⏺ Записать жесты»** — запись реальных рук для регрессионных тестов (`test/fixtures/`, реплей в `src/gestures/replay.test.ts`). `?worker=0` — детекция в главном потоке.
